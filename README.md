# KhetKhata & Fasal Doctor

Single-file, offline-first farm ledger and crop-schedule app (Hindi / Hinglish). Open `index.html` or host it as a static site.

- Data is stored only in the browser (`localStorage`). Use Export/Import JSON for backups.
- Crop dosages are indicative only; confirm with the product label and your local KVK / agriculture officer.
- Sample data ("Bada Khet") is fictional.
